# 🌐 Phase 6: Client Portal - AEGIS Platform

## 📋 סקירה כללית

**שם המודול:** Client Portal (פורטל לקוח)  
**מטרה:** ממשק ללקוחות הקצה לצפייה בנתונים, עדכון ליקויים וקבלת התראות  
**תלויות:** Phase 1-5 (כל המודולים הקודמים)  
**זמן פיתוח משוער:** 4-5 שבועות  

---

## 🎯 מה כולל המודול

| רכיב | תיאור | עדיפות |
|------|--------|--------|
| Dashboard | דשבורד ראשי עם סטטוס | 🔴 קריטי |
| Findings View | צפייה והגשת תיקונים לליקויים | 🔴 קריטי |
| Reports View | צפייה בדוחות ביקורת | 🔴 קריטי |
| Safety Files | צפייה בתיקי בטיחות | 🟠 גבוה |
| Training Status | סטטוס הדרכות עובדים | 🟠 גבוה |
| Documents | מסמכים ואישורים | 🟠 גבוה |
| Notifications | התראות ועדכונים | 🔴 קריטי |
| Profile & Settings | הגדרות משתמש | 🟡 בינוני |

---

## 👥 סוגי משתמשים בפורטל

| תפקיד | הרשאות | דוגמה |
|-------|--------|-------|
| **Admin** | צפייה בהכל + עדכון ליקויים + הגדרות | מנכ"ל, מנהל תפעול |
| **Manager** | צפייה בהכל + עדכון ליקויים | ממונה בטיחות, מנהל ייצור |
| **Viewer** | צפייה בלבד | עובד מורשה |

## 🖥️ ממשקים (UI Screens)

### Client Portal

| מסך | נתיב | תיאור |
|-----|------|--------|
| Dashboard | `/portal` | דשבורד ראשי |
| Findings | `/portal/findings` | רשימת ליקויים |
| Finding Detail | `/portal/findings/:id` | פרטי ליקוי + הגשת תיקון |
| Reports | `/portal/reports` | דוחות ביקורת |
| Report Detail | `/portal/reports/:id` | צפייה בדוח + PDF |
| Safety Files | `/portal/safety-files` | תיקי בטיחות |
| Safety File Detail | `/portal/safety-files/:id` | צפייה בתיק |
| Training | `/portal/training` | סטטוס הדרכות |
| Documents | `/portal/documents` | מסמכים ואישורים |
| Notifications | `/portal/notifications` | כל ההתראות |
| Profile | `/portal/profile` | פרופיל משתמש |
| Settings | `/portal/settings` | הגדרות (Admin בלבד) |

### Route Protection

```typescript
// ProtectedPortalRoute.tsx
const ProtectedPortalRoute = ({ children, requiredRole }) => {
  const { user, contact, loading } = usePortalAuth();
  
  if (loading) return <LoadingSpinner />;
  
  // לא מחובר
  if (!user) return <Navigate to="/portal/login" />;
  
  // אין גישה לפורטל
  if (!contact?.portalAccess?.enabled) {
    return <Navigate to="/portal/access-denied" />;
  }
  
  // בדיקת תפקיד
  if (requiredRole && contact.portalAccess.role !== requiredRole) {
    return <Navigate to="/portal/unauthorized" />;
  }
  
  return children;
};
```

## 🔥 Firestore Security Rules (הוספה)

```javascript
// Client Portal Rules
function isClientPortalUser(clientId) {
  return request.auth != null &&
    exists(/databases/$(database)/documents/tenants/{tenantId}/clients/$(clientId)/contacts/{contactId}) &&
    get(/databases/$(database)/documents/tenants/{tenantId}/clients/$(clientId)/contacts/{contactId}).data.portalAccess.authUid == request.auth.uid &&
    get(/databases/$(database)/documents/tenants/{tenantId}/clients/$(clientId)/contacts/{contactId}).data.portalAccess.enabled == true;
}

function getPortalUserRole(clientId) {
  return get(/databases/$(database)/documents/tenants/{tenantId}/clients/$(clientId)/contacts/{contactId}).data.portalAccess.role;
}

// Notifications - לקוח יכול לקרוא ולסמן כנקרא
match /notifications/{notificationId} {
  allow read: if isClientPortalUser(clientId) && 
    resource.data.recipientContactId == getContactId();
  allow update: if isClientPortalUser(clientId) && 
    request.resource.data.diff(resource.data).affectedKeys().hasOnly(['read', 'readAt']);
}

// Portal Activity - יצירה בלבד
match /portalActivity/{activityId} {
  allow create: if isClientPortalUser(clientId);
  allow read: if false; // רק דרך Admin
}
```
