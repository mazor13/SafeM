# 🛠️ ניהול ציוד (Equipment Management)

דף זה מאפשר למנהלי בטיחות לנהל את מלאי הציוד של הלקוח.

## מבנה טופס הציוד
הטופס בנוי בצורה היררכית כדי להבטיח אמינות נתונים:

### 1. סיווג ושיוך
כאן קובעים לאן הציוד שייך.
* **לקוח:** יש לבחור תחילה את הלקוח.
* **תחום:** בחירת תחום הבטיחות (למשל: כיבוי אש) תסנן את סוגי הציוד הרלוונטיים.

### 2. זיהוי ארגוני
* **מזהה פנימי:** מספר הנכס כפי שמופיע בספרי הארגון (חובה להיות ייחודי).
* **מיקום:** המערכת לומדת מיקומים קודמים ומציעה אותם להשלמה אוטומטית.

### 3. תקינה ובטיחות
כאן מגדירים מתי הציוד צריך להיבדק.
* **תדירות:** נגזרת אוטומטית מסוג הציוד, אך ניתנת לשינוי ידני.
